HELLDIVERS-BR — PATCH DO SITE / CENTRAL 01

Este pacote usa como base EXATA Helldivers-BR(9).zip enviado em 02/10/2026.
Só os arquivos alterados e novos foram incluídos. Nenhuma imagem foi removida.
O APP não foi modificado. Workflows de GitHub Actions não foram editados.

1. Faça uma cópia de segurança do projeto atual.
2. Extraia este ZIP e copie seu conteúdo para a raiz do projeto,
   substituindo somente os arquivos correspondentes. NÃO apague o projeto.
   Mantenha suas pastas de imagens e as outras pastas como estão.
3. Faça o deploy habitual do SITE. Já entram fila, prazo de 15 segundos,
   cache e diagnóstico. A fonte continua Community até ativar a central.
4. Leia central-api/LEIA-ME.md para publicar o Worker na Cloudflare,
   conferir as respostas e colocar a URL REAL em telemetry-config.js.
   O Worker não é um arquivo para subir no R2.
5. Publique telemetry-config.js atualizado para conectar o site à central.

IMPORTANTE: a central ainda NÃO foi publicada/ativada na sua conta.
Não há URL inventada neste patch. centralUrl está vazio por esse motivo.
Despachos e DSS mantêm Community na primeira etapa; veja o guia.
Não precisa trocar o APK, o JSON de atualização ou suas chaves.

273 planetas, 38 campanhas, 211 regiões no conjunto recebido.

Falta testar o Worker publicado e o comportamento no seu navegador.
